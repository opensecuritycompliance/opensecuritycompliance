## Notes

The required input files referenced in the rule YAML are available in the `TaskInputs` folder.

The following inputs are used by the rule:

- `fetch_s3_buckets_RequestConfigFile`
- `fetch_iam_users_RequestConfigFile`
- `fetch_cloudtrail_logs_RequestConfigFile`

All corresponding `RequestConfigFile` inputs are maintained under the `TaskInputs` directory and are used during rule execution.
