## Notes

The required input files referenced in the rule YAML are available in the `TaskInputs` folder.

The following inputs are used by the rule:

- `fetch_buckets_RequestConfigFile`
- `fetch_buckets_ResponseConfigFile`
- `check_encryption_RequestConfigFile`
- `check_encryption_ResponseConfigFile`

All corresponding `RequestConfigFile` and `ResponseConfigFile` inputs are maintained under the `TaskInputs` directory and are used during rule execution.
